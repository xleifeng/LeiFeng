# WebUI 第三方依赖

生产依赖均通过 npm 锁文件固定，完整许可文本可在对应包中查阅：

- Vue、Vue Router、Pinia：MIT
- TanStack Vue Query：MIT
- Zod：MIT
- qrcode：MIT
- Lucide：ISC
- @tanstack/vue-virtual 3.13.35：MIT
- reka-ui 2.10.1：MIT
- Vite、Vitest、Vue Test Utils、TypeScript：开发/测试工具，各自按其开源许可使用
- @playwright/test 1.62.1：开发/测试工具，Apache-2.0

本 WebUI 不包含迅雷 Electron renderer bundle，也不包含原 AriaNg 分发物。
